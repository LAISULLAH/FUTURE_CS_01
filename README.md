# FUTURE_CS_01

## Cyber Security Internship - Task 1

This repository contains the deliverables for Task 1 of the Future Interns Cyber Security Internship.

## Objective
Perform basic reconnaissance and passive security assessment on the OWASP Juice Shop application using industry-standard tools.

## Tools Used
- Nmap
- OWASP ZAP
- OWASP Juice Shop
- Git & GitHub

## Activities Performed
- Installed and configured OWASP Juice Shop
- Performed Nmap service discovery
- Conducted OWASP ZAP Passive Scan
- Generated security assessment report
- Documented findings

## Repository Structure

```
FUTURE_CS_01/
├── README.md
├── nmap/
├── report/
├── screenshots/
└── juice-shop/
```

## Findings
Some of the observations include:
- Missing Security Headers
- Content Security Policy (CSP) Header Not Set
- Missing Anti-clickjacking Header
- Information Disclosure
- Session Related Findings

## Disclaimer
This assessment was performed only on the intentionally vulnerable OWASP Juice Shop application in a controlled local environment for educational purposes.
